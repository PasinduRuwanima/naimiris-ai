# Current limitations

- Phase 1 is a foundation, not a complete farming advisory product.
- Only the health endpoint and frontend connectivity screen are implemented.
- Educational pages, reviewed disease entries, uploads, predictions, and the
  bilingual chatbot remain unimplemented.
- Dataset links have not been audited; no licenses, counts, labels, image
  suitability, or local botanical representation have been verified.
- No training, model comparison, checkpoint, ML result, or Nai Miris-specific
  performance claim exists.
- No agricultural claims, fertilizer rates, or pesticide doses are published.
- No LLM, retrieval corpus, Supabase database, authentication, or persistence is
  configured. The application does not accept or retain farmer images or chats.
- Sinhala Unicode is supported by the stack, but full translated content and
  language-quality evaluation are pending.
- Deployment, production load/security evaluation, and full responsive and
  accessibility audits remain future work. Health is HTTP liveness only.
